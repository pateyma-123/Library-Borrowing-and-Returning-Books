## Description

A comprehensive library management system designed to streamline the process of borrowing and returning books. This application provides an intuitive interface for managing book inventories, tracking borrowed items, and maintaining patron records.

## Features

- 📚 **Book Inventory Management** - Add, update, and organize library books
- 👥 **Patron Management** - Manage library member accounts and information
- 🔄 **Borrowing System** - Track borrowed books and due dates
- ✅ **Return Processing** - Simple and efficient book return workflow
- 📊 **Dashboard** - View statistics and library metrics
- 🔍 **Search Functionality** - Quickly find books and patron information

## Technology Stack

- **Python** (84.8%) - Backend logic and server-side processing
- **HTML** (10.3%) - Frontend markup and structure
- **CSS** (4.9%) - Styling and user interface design

## Installation

### Prerequisites

- Python 3.7 or higher
- pip (Python package manager)
- Modern web browser

### Setup Instructions

1. **Clone the repository**
   ```bash
   git clone https://github.com/pateyma-123/Library-Borrowing-and-Returning-Books.git
   cd Library-Borrowing-and-Returning-Books
   ```

2. **Create a virtual environment** (optional but recommended)
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

4. **Run the application**
   ```bash
   python app.py
   ```

5. **Access the application**
   - Open your browser and navigate to `http://localhost:5000`

## Usage

### For Patrons
1. Create an account or log in
2. Browse available books in the catalog
3. Select a book to borrow
4. Return books before the due date

### For Librarians
1. Manage book inventory and catalog
2. Process borrowing requests
3. Process book returns
4. View library statistics and reports
